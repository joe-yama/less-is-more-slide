# Spec Delta

## ADDED Requirements

### Requirement: ドット絵の表示の大きさ
スライドに貼るドット絵の大きさは、格子の長辺のドット数 n から決める SHALL。画像の長辺は、目標 2.4 インチを、n×0.05 インチ以上 n×0.075 インチ以下に収めた値とし、さらに 4.6 インチを超えないようにする SHALL。短辺は格子の縦横比を保つ。この規則は図のレイアウトと左右 2 列のレイアウトのどちらの画像にも同じく当てはめる SHALL。

#### Scenario: 粗い格子は小さく貼る
- **WHEN** 8×8 の格子を図のレイアウトで貼る
- **THEN** 画像は 0.6 インチ四方である

#### Scenario: 同梱アイコン
- **WHEN** `icon:gear`（16×16）を図のレイアウトで貼る
- **THEN** 画像は 1.2 インチ四方である

#### Scenario: 目標に届く格子
- **WHEN** 32×32 の格子と 40×40 の格子を、それぞれ図のレイアウトで貼る
- **THEN** どちらの画像も 2.4 インチ四方である

#### Scenario: 細かい格子は大きく貼る
- **WHEN** 64×64 の格子を図のレイアウトで貼る
- **THEN** 画像は 3.2 インチ四方である

#### Scenario: 長辺の頭打ち
- **WHEN** 200×200 の格子を図のレイアウトで貼る
- **THEN** 画像は 4.6 インチ四方である

#### Scenario: 縦横比を保つ
- **WHEN** 幅 32、高さ 16 の格子を図のレイアウトで貼る
- **THEN** 画像は幅 2.4 インチ、高さ 1.2 インチである

#### Scenario: 左右 2 列の画像
- **WHEN** 左右 2 列のレイアウトの右に `![箱](icon:box)` を書く
- **THEN** 右の画像は 1.2 インチ四方である

### Requirement: 図の説明文の位置
図のレイアウトの説明文は、画像と同じ高さから始め、左端を画像の右端から 0.5 インチ右に置く SHALL。

#### Scenario: 小さな画像の説明文
- **WHEN** `icon:gear` と説明文 `毎晩 2 時に動く。` を持つ図のスライドを作る
- **THEN** 説明文の枠の左端は画像の右端から 0.5 インチ右にあり、枠の上端は画像の上端と同じである
