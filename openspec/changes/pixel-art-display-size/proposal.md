# Proposal

## Why

生成器は、ドット絵をドット数に関係なく長辺 4.6 インチに引き伸ばして貼る。8×8 の絵では 1 ドットが約 0.58 インチ、16×16 の同梱アイコンでも約 0.29 インチになり、PowerPoint で見ると粒が大きすぎて不格好に見える。ドット数（ピクセル密度）から貼る大きさを決め、粒の大きさを揃える。

## What Changes

- ドット絵の表示の大きさを、格子の長辺のドット数から決める。目標は長辺 2.4 インチ。ただし 1 ドットは 0.05〜0.075 インチに収める。このため、目標に届くのは 32〜48 ドットの絵で、それより粗い絵は小さく、細かい絵は大きく表示される。長辺は 4.6 インチ（いまの上限）を超えない。図のレイアウトと左右 2 列のレイアウトの両方に適用する。
- 図のレイアウトの説明文は、実際の画像の右端から一定の間を空けて置く（画像が小さくなっても、説明文が離れすぎない）。
- **BREAKING**（緩和）: 格子の幅と高さの上限 64 ドットを外す。65 ドット以上の格子も受け付ける。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `pixel-art`: 「格子ファイルの書式」を、幅と高さの上限 64 を外した「格子ファイルの書式と大きさ」に置き換える。
- `slide-generation`: ドット絵の表示の大きさと、図の説明文の位置の要件を加える。

## Impact

- 変更: `plugin/skills/slide/scripts/slidekit/render.py`（画像の大きさ、PNG の拡大率、説明文の位置）、`plugin/skills/slide/scripts/slidekit/grid.py`（上限の削除）、`tests/test_render.py`、`tests/test_grid.py`、`plugin/skills/slide/SKILL.md` と `plugin/skills/slide/references/format.md`（「1〜64」の記述）。
- 依存の追加はない。
- 対象外: 同梱アイコン 14 個の描き直し（16×16 のまま、表示は 1.2 インチになる）、原稿から大きさを指定する書式、ドット絵ツール（`pixel.py`）の拡大率の範囲（1〜64 のまま）。
