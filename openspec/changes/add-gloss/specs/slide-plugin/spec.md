## MODIFIED Requirements

### Requirement: Skill の内容
Skill `slide` は、原稿の書式（6 種のレイアウト、強調、画像の参照、添え訳）、生成器とドット絵ツールのコマンド、文章と構成の書き方の規則（AI っぽさの一覧と、添え訳は本文と同じ意味にし情報を足したり削ったりしないという規則を含む）、作成役と点検役の使い方を書く SHALL。添え訳については、書き方、つけられる対象、文字の大きさ、行数の上限、拒否される書き方を書く SHALL。Skill に書いたコマンドと原稿の例は、書いてあるとおりに動かなければならない SHALL。

#### Scenario: Skill の例がそのまま通る
- **WHEN** Skill に載っている原稿の例を、Skill に載っているコマンドで生成する
- **THEN** 終了コード 0 で PPTX ができる

#### Scenario: 6 種のレイアウトがすべて載っている
- **WHEN** Skill を読む
- **THEN** 表紙、一言、箇条書き、図、表、左右 2 列の書き方がそれぞれ載っている

#### Scenario: 添え訳の例が載っている
- **WHEN** Skill の「原稿の書式（最短）」を読む
- **THEN** `^ ` で始まる添え訳の行を含む原稿の例があり、その例は生成できる

#### Scenario: 添え訳の書き方の規則
- **WHEN** Skill の書式の説明と書き方の規則を読む
- **THEN** 添え訳の書き方・対象・大きさ・上限・拒否される書き方と、添え訳は本文と同じ意味にし情報を足したり削ったりしないという規則が書いてある

### Requirement: 作成役 Agent
Agent `writer` は、主題と材料を受け取り、Skill `slide` の規則で原稿を書き、生成器で PPTX を作る SHALL。添え訳を書くときは、本文と同じ意味にし、片方にしかない情報を作らない SHALL。生成器が拒否したら理由に沿って原稿を直し、成功するまで生成し直す SHALL。PPTX を直接編集したり、生成器以外の方法でスライドを作ったりしてはならない SHALL NOT。最後に原稿と PPTX のパスを返す SHALL。

#### Scenario: 主題からスライドを作る
- **WHEN** 作成役に主題と 3 行の材料を渡す
- **THEN** 原稿と PPTX ができ、作成役の返答に両方のパスがある

#### Scenario: 添え訳を書くときの観点
- **WHEN** 作成役の定義を読む
- **THEN** 添え訳を本文と同じ意味にし、片方にしかない情報を作らないことが書いてある

### Requirement: 点検役 Agent
Agent `critic` は、原稿を読むだけで書き換えない SHALL（使える道具は読み取りだけ）。Skill の AI っぽさの一覧と書き方の規則に照らし、指摘ごとにスライド番号、該当する文の引用、当たる規則、書き直しの案を返す SHALL。原稿に添え訳があるときは、添え訳と本文の意味が合っているか、片方にしかない情報がないかも点検する SHALL。指摘がなければ、ないとだけ返す。

#### Scenario: 道具が読み取りだけ
- **WHEN** 点検役の定義を読む
- **THEN** 使える道具に、ファイルを書き換える道具とコマンドを実行する道具がない

#### Scenario: 仕込んだ AI っぽさを見つける
- **WHEN** AI っぽさの一覧から 5 種を 1 つずつ仕込んだ原稿を点検役に渡す
- **THEN** 少なくとも 4 種について、スライド番号と引用と書き直しの案を持つ指摘が返る

#### Scenario: 添え訳を点検する観点
- **WHEN** 点検役の定義を読む
- **THEN** 添え訳と本文の意味が合っているか、片方にしかない情報がないかを点検することが書いてある
