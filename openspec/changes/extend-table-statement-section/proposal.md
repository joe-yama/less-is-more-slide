# Proposal

## Why

設計の相談の資料（18 枚）を作ったとき、表・一言・区切りの 3 か所で、この Skill の書式では足りなかった。4 列で文字の多い比べる表は 18pt で入らず、推す案の列を示す書き方がなかった。結論の下に補足を置けず、一言とセルの改行位置も決められなかった。本編のあとに「補足資料」の区切りも置けなかった。構成図（変更 `add-flow-diagram`）に続いて、これらを原稿から作れるようにする。

## What Changes

- 表: 18pt で入らない表は、表全体を 16pt で判定し直す（1 段だけ）。16pt でも入らなければ、今までどおり拒否する。
- 表: 見出しのセル全体を `**…**` で囲むと、その列を強調する。見出しの文字を強調色にし、列全体を強調色の 1.5pt の枠で囲む。強調の 1 か所と数える。見出しのセルの一部だけを `**` で囲んだものは拒否する。**BREAKING**: 見出しのセルの一部を `**` で囲んだ今の原稿は、拒否されるようになる。セル全体を囲んだ原稿は、列に枠が付くようになる。
- 改行 `<br>`: 一言とその補足、表のセルに書ける。ほかの場所の `<br>` は拒否する。
- 一言: 見出しのないスライドは、1 行目を一言（40pt のまま）、続く 1〜2 行を補足（24pt、灰色）とする。補足にも添え訳をつけられる。
- 中扉: 2 枚目以降で `# タイトル` の 1 行だけのスライドを中扉とする。表紙のタイトルと同じ大きさと位置に置き、ページ番号を付ける。レイアウトは 7 種になる。
- 見出しの長さ（27 字を超えたら 30pt から縮める）は採らず、今のまま拒否する。最後の行が短い一言の判定も採らない（文字幅の見積もりでは、PowerPoint の折り返し位置を当てられない）。
- Skill の文書（`SKILL.md`、`references/format.md`、`references/writing.md`）を更新し、見本の原稿 `examples/design-review.md` に表・一言・中扉のスライドを足す。プラグインの版を 0.4.0 に上げる。

## Capabilities

### New Capabilities

なし。

### Modified Capabilities

- `slide-generation`: 「原稿の区切りと表紙」（中扉）、「一言レイアウト」（補足）、「表レイアウト」（16pt と列の強調）、「未対応の書式の拒否」（7 種、`<br>`）、「添え訳の書式」「添え訳の文字」（補足・中扉・16pt の表）を変え、改行・中扉・表の大きさ・列の強調の要件を加える。
- `slide-plugin`: 「Skill の内容」を 7 種のレイアウトと、改行・補足・列の強調にする。

## Impact

- 変更: `plugin/skills/slide/scripts/slidekit/` の `fit.py`・`manuscript.py`・`render.py`、`plugin/skills/slide/SKILL.md`、`references/format.md`・`writing.md`、`plugin/.claude-plugin/plugin.json`、`.claude-plugin/marketplace.json`、`examples/design-review.md`、`tests/` の各テスト。
- 前提: 変更 `add-flow-diagram` がマージされ、アーカイブされていること（見本の原稿と、`slide-plugin` の「Skill の内容」の文が、その変更の後の形を前提にしている）。
- 依存の追加はない。
- 対象外: 一言の 3 段目（20pt の灰色の文）、一言の 44pt、見出しの縮小、最後の行の短さの判定、2 段以上の表の縮小、表の列ごとの幅の指定。
