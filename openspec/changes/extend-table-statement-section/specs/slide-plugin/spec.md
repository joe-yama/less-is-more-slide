## MODIFIED Requirements

### Requirement: Skill の内容
Skill `slide` は、原稿の書式（7 種のレイアウト、強調、表の列の強調、改行 `<br>`、画像の参照、添え訳、構成図）、生成器とドット絵ツールのコマンド、文章と構成の書き方の規則（AI っぽさの一覧と、添え訳は本文と同じ意味にし情報を足したり削ったりしないという規則を含む）、作成役と点検役の使い方を書く SHALL。添え訳については、書き方、つけられる対象、文字の大きさ、行数の上限、拒否される書き方を書く SHALL。構成図については、構成図ファイルの 4 種の行の書き方、配置の決まり方、図の強調の数え方、拒否される書き方と、構成図を使うのは構成や流れを説明するときだけという規則を書く SHALL。一言の補足、改行を書ける場所、表が 16pt になる条件を書き、2 行以上になる一言は意味の切れ目で `<br>` を入れるという規則を書く SHALL。Skill に書いたコマンドと原稿の例は、書いてあるとおりに動かなければならない SHALL。

#### Scenario: Skill の例がそのまま通る
- **WHEN** Skill に載っている原稿の例を、Skill に載っているコマンドで生成する
- **THEN** 終了コード 0 で PPTX ができる

#### Scenario: 6 種のレイアウトがすべて載っている
- **WHEN** Skill を読む
- **THEN** 表紙、一言、箇条書き、図、表、左右 2 列の書き方がそれぞれ載っている

#### Scenario: 中扉の書き方が載っている
- **WHEN** Skill を読む
- **THEN** 中扉の書き方が載っていて、その原稿の例は生成できる

#### Scenario: 添え訳の例が載っている
- **WHEN** Skill の「原稿の書式（最短）」を読む
- **THEN** `^ ` で始まる添え訳の行を含む原稿の例があり、その例は生成できる

#### Scenario: 添え訳の書き方の規則
- **WHEN** Skill の書式の説明と書き方の規則を読む
- **THEN** 添え訳の書き方・対象・大きさ・上限・拒否される書き方と、添え訳は本文と同じ意味にし情報を足したり削ったりしないという規則が書いてある

#### Scenario: 構成図の例がそのまま通る
- **WHEN** Skill の書式の説明に載っている構成図ファイルの例を読み、それを参照する原稿の例を生成する
- **THEN** どの構成図ファイルの例も受け付けられ、原稿の例は終了コード 0 で PPTX になる

#### Scenario: 構成図の書き方の規則
- **WHEN** Skill の書式の説明と書き方の規則を読む
- **THEN** 構成図ファイルの 4 種の行、図の強調の数え方、拒否される書き方と、構成図を使うのは構成や流れを説明するときだけという規則が書いてある

#### Scenario: 補足・改行・列の強調の例
- **WHEN** Skill の書式の説明を読み、その原稿の例を生成する
- **THEN** 一言の補足、`<br>` の改行、表の列の強調を含む原稿の例があり、終了コード 0 で PPTX になる。書き方の規則に、2 行以上になる一言は意味の切れ目で `<br>` を入れることが書いてある
